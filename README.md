# EXIF 信息工具

> Windows 图形界面 EXIF 编辑器：**时间修复** + **14 项字段自定义写入**
>
> Bilibili: [@何止有点帅](https://space.bilibili.com/702444737)

一个软件、两个功能模块（页面顶部标签切换，默认显示「EXIF 时间修复工具」）。

## 功能

### 🕐 EXIF 时间修复工具

- **修复规则**：① 有拍摄日期的照片 → EXIF 修改/数字化时间统一为拍摄日期；② 无拍摄日期的照片（截图等）→ 用文件修改日期填充 EXIF 时间
- 两种选择模式：文件夹路径自动扫描（可含子文件夹）/ Windows 原生对话框手动多选（可跨文件夹累积选择）
- 两种保存方式：**backup**（备份原图片后原地修改）/ **changed**（原图片不动，另存修改后图片）
- 预览清单：行勾选/全选、单行删除、清空、列头点击排序、所在文件夹列
- 可选：文件修改时间同步为拍摄日期

### ✏️ EXIF 信息修改工具

自定义勾选写入/修改 14 项 EXIF 字段（单项或多项）：

相机制造商 / 相机型号 / 软件 / 拍摄日期 / 闪光灯 / 焦距 / 焦距 35mm / 快门速度 / 曝光偏差 / 光圈数 / ISO 感光度 / 曝光程序 / 测光模式 / 旋转信息

## 下载

直接下载仓库中的 **`EXIF信息工具.exe`**（免安装单文件，Windows 10/11 64 位）。

或从 [Releases](https://github.com/stfizer/exif-tool/releases) 页面获取历史版本。

## 使用

1. 双击 `EXIF信息工具.exe`，浏览器自动打开操作页面（`http://127.0.0.1:8780`）
2. 勾选要写入的字段（信息修改 Tab）或直接使用规则修复（时间修复 Tab）
3. 选择图片 → 预览 → 勾选需要处理的图片 → 应用修改

详细说明见 [使用说明.txt](使用说明.txt)。

## 支持格式

| 格式 | 说明 |
|---|---|
| JPG / JPEG | ✅ 无损（字节级替换 EXIF 段，像素不动） |
| PNG | ✅ 无损（eXIf 块写入） |
| HEIC / HEIF | ⚠️ 重存 q95，轻微有损 |

## 技术栈

Python + Pillow / piexif / pillow-heif，内置 Web 界面（纯前端，无外部依赖）。

构建 exe：

```bash
pip install pillow piexif pillow-heif pyinstaller
pyinstaller --onefile --name "EXIF信息工具" exif_tool.py
```

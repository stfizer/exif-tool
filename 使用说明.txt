【这是什么】
「EXIF 时间修复工具」与「EXIF 信息修改工具」的合并版：
一个软件、两个功能模块，页面顶部标签点击切换，
**默认显示「EXIF 时间修复工具」**。
独立软件，与之前分开的两个工具互不影响，可同时运行
（本工具端口 8780，时间修复工具 8765，信息修改工具 8770）。

【启动方法】
◆ 分享/日常使用：双击「EXIF信息工具.exe」（免安装单文件，无需
  安装 Python），浏览器自动打开操作页面（地址 http://127.0.0.1:8780），
  首次启动需解压，稍等 3~10 秒。分享给别人时把这个 exe 发过去即可。
◆ 源码方式：双击「启动EXIF信息工具.bat」运行 exif_tool.py
  （需要本机 Python + Pillow/piexif/pillow-heif 环境）。
两种方式的黑色窗口都是运行后台，最小化即可；关闭它 = 退出工具。

【默认选项】
- 「包含子文件夹」默认**不勾选**（只扫所选文件夹这一层；
  照片在子文件夹里时请自行勾选）
- 保存方式默认选**「原图片不动，修改后另存到 changed\」**
  （backup 方式备选；changed 方式下"文件修改时间同步"自动失效置灰）

【Tab 1：EXIF 时间修复工具】（默认）
修复规则：
  ① 有拍摄日期的照片 → EXIF 的修改时间/数字化时间统一为拍摄日期
  ② 无拍摄日期的照片（截图等）→ 用文件修改日期填充 EXIF 时间
- 两种选择模式：路径自动扫描（可含子文件夹）/ Windows 对话框手动多选
- 两种保存方式：backup（备份原图后原地修改）/ changed（原图不动另存）
- 表头点击排序（文件名/所在文件夹/日期等 6 列）、所在文件夹列、
  CSV 报告、文件修改时间同步为拍摄日期（仅 backup 方式）
- 自动排除 backup\changed\_exif_backup 与工具自身目录

【Tab 2：EXIF 信息修改工具】
自定义勾选写入/修改 14 项 EXIF 字段（单项或多项）：
  相机制造商、相机型号、软件、拍摄日期、闪光灯、焦距、焦距35mm、
  快门速度、曝光偏差、光圈数、ISO 感光度、曝光程序、测光模式、旋转信息
- 勾选字段并填写内容 → 选择图片 → 应用修改
- 拍摄日期写入时同步更新 EXIF 三项时间
- 旋转信息只改 EXIF 标记不改像素（看图软件按标记旋转显示）
- 同样支持 backup / changed 两种保存方式

【支持格式】
JPG / JPEG / PNG / HEIC / HEIF（JPG、PNG 无损，HEIC 重存 q95）

【退出方法】
任一页面点「退出工具」按钮，或直接关闭黑色控制台窗口
（退出会同时结束两个模块）。

【常见问题】
Q: 双击后没反应？
A: 首次启动稍慢，等几秒；浏览器没自动打开就手动访问
   http://127.0.0.1:8780
Q: 杀毒软件报毒？
A: Python 打包/运行的常见误报，加入信任即可。
Q: 想恢复修改前状态？
A: backup 方式从 backup\ 文件夹复制回去覆盖；
   changed 方式原文件本来就没动过。
